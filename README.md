#Números Pseudoaleatórios e Testes de Primalidade  

Este projeto implementa algoritmos de geração de números pseudoaleatórios (**LCG** e **XORSHIFT**) e algoritmos de testes probabilísticos de primalidade (**Miller-Rabin** e **Fermat**).  
Além disso, realiza comparações de desempenho entre os métodos e gera arquivos **CSV** com os resultados.  

---

## Como executar  

### 1. Programa principal  
O arquivo principal é o **`main.py`**, que contém um menu interativo para o usuário escolher a ação desejada.  

```bash
python main.py 
```
